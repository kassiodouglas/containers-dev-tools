Prompt para IA corrigir os problemas

Inclui falhas de Quality Gate e as issues disponíveis no JSON. O prompt orienta a IA a validar o repositório antes de propor mudanças.

Ao buscar, o navegador envia a URL e o token do ambiente ativo ao proxy local, que os utiliza somente para consultar o SonarQube. Não exponha o proxy na rede. Respostas paginadas ou filtradas podem não conter todas as issues. Métricas de New Code são relativas ao período configurado, não necessariamente à última execução do scanner.
